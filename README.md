# Rajib Tv Show

GitHub Pages-ready static TV interface.

## Deploy
1. Upload `index.html`, `style.css`, `app.js`, and `channels.json` to a GitHub repository.
2. Open **Settings → Pages**.
3. Select the branch/root folder and save.
4. Open the generated GitHub Pages URL.

The channel data is parsed from the supplied M3U playlist. Stream availability depends on the original stream server, CORS policy, HTTPS compatibility, geo-blocking, and whether the stream is still active.
